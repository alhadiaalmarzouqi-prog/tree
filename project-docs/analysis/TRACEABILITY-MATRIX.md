**الحالة:** إطار تتبع فقط. كل الحالات "غير منفَّذة" أو "غير مُختبَرة"، ولا يُغيَّر أي منها إلا بدليل من تنفيذ حقيقي.
**المرجع:** `REQUIREMENTS.md`
**مفاتيح الحالة:** `مفتوح` = لم يُصمَّم بعد، `مُصمَّم` = وُثِّق في وثيقة معتمدة، `مُنفَّذ` = موجود في الكود ومُراجَع، `مُختبَر` = نجح اختبار مسمى. الحالة الحالية لكل المتطلبات: `مفتوح`.
**مفاتيح المرحلة:** مراحل المشروع 0–7 كما وردت في المواصفة (§13).
**ملاحظة:** "التصميم" يشير إلى الوثيقة المتوقعة التي ستكتب في الجلسة 2 أو الجلسة 3.
