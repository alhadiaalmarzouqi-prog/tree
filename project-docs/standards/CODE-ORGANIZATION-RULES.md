# CODE-ORGANIZATION-RULES — قواعد تنظيم الكود

**الحالة:** ملزمة لكل مرحلة تنفيذ، وتحتاج موافقة المالك قبل التطبيق.

## 1. المبدأ
كل ملف له مسؤولية واحدة واضحة. لا يُضاف منطق جديد إلى ملف كبير لمجرد تشابهه مع الموجود؛ يُقيَّم أولاً هل يستحق وحدة مستقلة.

## 2. الحدود
| الحد | القيمة | الإجراء |
|---|---|---|
| الهدف المعتاد لكل ملف مصدر | 300–500 سطر | مقبول |
| عتبة المراجعة الصارمة | 700 سطر | يجب تقسيم الملف أو توثيق سبب مقنع |
| الحد الأقصى المقبول بعد الاستثناء | لا يُتجاوز دون موافقة المالك | يُسجَّل الاستثناء في `DECISIONS.md` |

ملاحظة: نص مهمة التخطيط ذكر 900 سطر. تعتمد هذه الوثيقة 700 كعتبة صارمة، لأنها الأكثر تقييداً (CG-42).

## 3. قواعد إلزامية
1. كل ميزة أو مهمة أو مسؤولية لها وحدة أو ملف باسم واضح.
2. ممنوع دمج: خدمات مختلفة، عمليات قاعدة البيانات، مكونات الواجهة، قواعد التحقق، منطق الأعمال في ملف واحد.
3. يُقسَّم المكون الكبير إلى مكونات أصغر قابلة لإعادة الاستخدام.
4. تُفصل النماذج (Models)، والمخططات (Schemas)، والمستودعات (Repositories)، والخدمات (Services)، والمتحكمات (Controllers)، ووحدات التحقق (Validators)، والاختبارات حسب البنية المعتمدة.
5. لا تُنشأ أجزاء بلا معنى فقط لتقليل عدد الأسطر، ولا تُفصل منطق مترابط بلا سبب.
6. كل ميزة جديدة تأتي معها اختبارات منفصلة.
7. أسماء الملفات والمجلدات تعبّر عن المسؤولية (مثال: `kinship-path.service.ts` بدلاً من `utils.ts`).
8. تُطبَّق القواعد على الخادم، والتطبيق، والويب إن وُجد، وقاعدة البيانات (ملفات الترحيل)، والاختبارات.

## 4. قيود التنفيذ
- ممنوع تكرار منطق الأعمال في أكثر من مكان. يُستخدم مصدر واحد للقرابة.
- ممنوع تجاوز عتبة 700 سطر في تسليم مرحلة دون تقسيم أو استثناء معتمد.
- ممنوع إنشاء ملفات مرجعية عامة مثل `helpers.ts` أو `common.ts` تجمع أشياء غير مرتبطة.
- ممنوع استخدام بيانات وهمية كدليل على نجاح الوحدة.

## 5. التحقق
- قبل التسليم يُسجَّل عدد أسطر كل ملف جديد أو مُعدَّل مع أكبر ملفين.
- أي ملف فوق 700 سطر يُذكر في تقرير المرحلة مع السبب والإجراء.
- المراجع المستقل يتحقق من هذا القسم قبل اعتماد المرحلة.

## 6. المعايير المرتبطة
تفاصيل التسمية والمعالجة والتسجيل والاختبار تُحدَّد في `TEST-STRATEGY.md` و`MASTER-ARCHITECTURE.md` بعد الموافقة على التحليل، ولا تُكتب هنا لتجنب التكرار.
